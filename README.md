# AltSchool Capstone Project

This repository contains three full-stack projects built for the AltSchool Frontend Engineering Karatu 2025 Third Semester Capstone.

## Projects

- **Chatter** — A multi-functional publishing platform for writers and readers
- **Scissor** — A URL shortener with analytics, QR codes, and custom slugs
- **Carefinder** — A hospital directory for Nigerians with search, export, and map features
